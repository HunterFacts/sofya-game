# Sofya Car — машинки Софьи 🚙💗

Игра в духе Hill Climb Racing для телефона: розовый джип-пикап едет по холмам, за рулём Софья, во втором окне кошка Марисса.

**Играть:** https://hunterfacts.github.io/sofya-game/ (после включения GitHub Pages)

## Что есть в игре

- Бесконечные уровни по 2–3 минуты. Миры меняются: луг → конфетная страна → пустыня → зима → осенний лес → луна → пляж, и дальше по кругу, холмы с каждым кругом круче.
- Финиш: 3 звезды, или 2, если собрано меньше половины монет. Машина не останавливается и едет в следующий уровень.
- Перевернулась — уровень начинается заново, монеты остаются.
- Ускорялки: ⚡ турбо, 🧲 магнит, 🛡️ щит. Подбираются на трассе или покупаются.
- Сундуки за каждый уровень и на трассе: монеты, ускорялки, иногда новый зверёк, раскраска или шапочка.
- Гараж: скорость, колёса, равновесие, сила турбо и магнита; 11 раскрасок, 8 зверят (Марисса, собачка, зайка, панда, лисичка, мишка, пингвин, единорог), 9 шапочек.
- Почти без текста: всё понятно по картинкам. Звуки и музыка генерируются прямо в браузере.
- Прогресс хранится в браузере телефона. После закрытия игра продолжается с того же места.

## Управление

- Правая половина экрана — газ, левая — тормоз/назад. В воздухе газ наклоняет машину назад, тормоз — вперёд.
- На компьютере: стрелки или A/D, 1/2/3 — ускорялки, Esc — пауза.
- Кнопка ⛶ (в меню и на паузе) — полный экран, 📱↻ — повернуть экран (там, где браузер это умеет, например Android Chrome). При нажатии ▶ на телефоне игра сама пытается включить полный экран и горизонтальную ориентацию.

## Как поставить на телефон

Игра работает **без интернета**: при первом открытии с интернетом все её файлы сохраняются на телефоне. Когда это готово, в меню рядом с монетками появляется значок **✈️✓**. Прогресс (монеты, уровни, сундуки, зверята) тоже хранится на самом телефоне.

**Android (Chrome)**
1. С интернетом откройте ссылку именно в Chrome, а не внутри Telegram или ВК. Дождитесь ✈️✓ в меню.
2. Меню ⋮ → «Добавить на главный экран» (или «Установить приложение»).
3. Проверка: режим полёта → открыть с иконки. Иконка и Chrome делят одну память, прогресс общий.

**iPhone (Safari)**
1. С интернетом откройте ссылку именно в Safari. Если ссылка открылась внутри Telegram или ВК, игра сама попросит открыть её в Safari.
2. «Поделиться» → «На экран „Домой“».
3. **Откройте игру с иконки, пока есть интернет**, и дождитесь ✈️✓. У иконки на iPhone своя, отдельная от Safari память.
4. Дальше играйте **только с иконки**. В Safari прогресс стирается, если неделю не играть, а у иконки не стирается.
5. Если уже играли в Safari: в Safari нажмите «📋 Скопировать прогресс» (подсказка про iPhone появляется при каждом запуске в Safari), затем в игре с иконки нажмите «📥 Вставить прогресс из Safari». Эта кнопка видна, пока в иконке ещё нет своего прогресса.

**Для родителей (скрыто от ребёнка):** в меню 3 секунды держите надпись «Sofya Car». Откроется панель: скопировать прогресс (резервная копия, перенос на другой телефон), вставить прогресс, сбросить прогресс. Сброс просит подтверждения: кнопку нужно держать 2 секунды; отмена — крестик ✕. Настройки звука при сбросе сохраняются.

**Чтобы прогресс не пропал:** не очищайте данные сайта и историю. На iPhone не удаляйте иконку: вместе с ней удаляется её память.
Без интернета открывайте игру с иконки или по адресу **со слешем на конце**: `…/sofya-game/`.

## Публикация (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
Сборка не нужна: это обычные статические файлы (HTML + JS-модули + canvas), без зависимостей.

### Выпуск новой версии (важно для офлайн-режима)

Игра всегда запускается из офлайн-пакета на телефоне. Новая версия скачивается, только если изменился `VERSION` в `sw.js`. Тогда телефон при следующем запуске с интернетом скачивает её **целиком** (если связь оборвётся, остаётся старая рабочая версия) и включает при выходе в меню или при следующем запуске.

- При любом изменении файлов игры увеличивайте `VERSION` в `sw.js`.
- Новый файл (js, картинку) впишите в список `FILES` в `sw.js`.

Git-хук делает это сам: подключите его один раз командой `sh tools/install-hooks.sh`. После этого каждый коммит с изменёнными файлами игры сам повышает `VERSION` и проверяет список `FILES`.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Устройство кода

| Файл | Что внутри |
|---|---|
| `js/config.js` | все настройки: физика, цены, миры, раскраски, зверята, шапочки, сундуки |
| `js/terrain.js` | бесконечная трасса, уровни, монетки, украшения |
| `js/car.js` | физика машины (кузов + колёса на пружинах) |
| `js/world.js` | заезд: монеты, бонусы, финиш, авария, частицы |
| `js/render.js` | отрисовка мира |
| `js/art.js` | рисунки: машина, Софья, зверята, шапочки, деревья |
| `js/ui.js` | гараж, сундуки, карта уровней |
| `js/audio.js` | звуки и музыка (Web Audio) |
| `js/save.js` | сохранение в localStorage |
| `js/main.js` | экраны, управление, игровой цикл, перенос прогресса |
| `sw.js` | офлайн-режим (пакет файлов на телефоне) |
| `tools/pre-commit` | git-хук: повышает `VERSION` в `sw.js` и проверяет список файлов |
